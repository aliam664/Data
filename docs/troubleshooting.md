# عیب‌یابی UHM Launcher

## لانچر باز نمی‌شود

- `UHM-Launcher.cmd` را از داخل پوشه Extractشده اجرا کنید، نه داخل ZIP.
- Windows باید 10/11 و PowerShell حداقل 5.1 باشد.
- اگر Execution Policy سازمانی اجرای `-File` را کاملاً block کرده، با مدیر سیستم تماس بگیرید؛ Policy امنیتی را دائمی دور نزنید.
- فایل روز جاری در `data/logs` را بررسی کنید.

## پنجره Native باز نمی‌شود

- برنامه را از `UHM-Launcher.cmd` اجرا کنید تا PowerShell با `-STA` شروع شود.
- وجود Assemblyهای `PresentationFramework` و WPF در Windows 10/11 را بررسی کنید.
- خطای XAML یا STA در پنجره CMD و `data/logs` ثبت می‌شود.
- `wpf/MainWindow.xaml` را مستقیم باز نکنید؛ رفتار کلیک‌ها در `UHM-Wpf.ps1` متصل می‌شود.

## حالت Legacy می‌گوید Token وجود ندارد

این پیام فقط در رابط HTML قدیمی دیده می‌شود. `ui/index.html` مستقیم باز شده است؛ حالت Legacy باید از `UHM-Core.ps1 -Action launch-web` اجرا شود.

## Bridge قطع می‌شود

Bridge عمداً فقط روی Loopback و تا زمانی که heartbeat UI برسد فعال است. Sleep طولانی، بستن برگه یا ابزار امنیتی می‌تواند آن را متوقف کند. CMD را دوباره اجرا و روی Retry بزنید؛ فایل `.part` حفظ شده است.

## مسیر Assetto Corsa پیدا نشد

مسیر صحیح معمولاً این است:

```text
D:\SteamLibrary\steamapps\common\assettocorsa
```

پوشه باید `AssettoCorsa.exe`، `content/cars` و `content/tracks` داشته باشد. مسیر `steamapps/common` یا پوشه Content Manager معتبر نیست. اگر چند Steam Library دارید، Settings → تست Steam را اجرا کنید.

## دانلود به «نیازمند دانلود دستی» رفت

لینک به HTML، CAPTCHA، Login یا صفحه واسط رسیده است. UHM آن را دور نمی‌زند و موفق گزارش نمی‌کند. صفحه رسمی را باز کنید. Import امن فایل دستی هنوز در UI نسخه 0.1.0 وجود ندارد.

## دانلود ناقص است یا Resume نمی‌شود

Cancel فایل `.part` را نگه می‌دارد. Retry Header Range می‌فرستد. اگر سرور به‌جای 206 پاسخ 200 دهد، UHM از truncate خودکار خودداری می‌کند. رکورد را Remove کنید و در سؤال دوم حذف فایل ناقص را تأیید کنید، سپس مود را دوباره به صف اضافه کنید.

## حجم یا SHA-256 مطابقت ندارد

فایل نهایی ساخته نمی‌شود و `.part` برای بررسی باقی می‌ماند. ممکن است لینک عوض شده، کاتالوگ قدیمی، دانلود خراب یا سرور صفحه خطا فرستاده باشد. فایل مشکوک را اجرا نکنید. مدیر کاتالوگ باید حجم/Hash رسمی را بازبینی کند.

## 7-Zip پیدا نشد

UHM این مسیرها و PATH را بررسی می‌کند:

- `%ProgramFiles%\7-Zip\7z.exe`
- `%ProgramFiles(x86)%\7-Zip\7z.exe`
- `7z.exe` در PATH

7-Zip رسمی را با تأیید خودتان نصب کنید و Launcher را از نو اجرا کنید. نصب خودکار انجام نمی‌شود.

## رمز آرشیو صحیح نیست

Password فقط از رکورد کاتالوگ خوانده می‌شود. فاصله و بزرگی حروف مهم است. UHM رمز دیگری حدس نمی‌زند و تکرار بی‌نهایت ندارد. مدیر کاتالوگ باید رمز عمومی سازنده را اصلاح کند.

## «مسیر آرشیو امن نیست»

آرشیو Entry مطلق، `..`، Drive/UNC، symlink یا Reparse Point دارد. این محافظت را غیرفعال نکنید. مود را به مدیر کاتالوگ گزارش کنید.

## هشدار فایل اجرایی/Script

UHM آن فایل را اجرا نمی‌کند، اما نصب آن فقط پس از تأیید انجام می‌شود. بعضی Appها DLL معتبر دارند؛ EXE/Script غیرمنتظره را با منبع و Hash رسمی بررسی کنید. DLL ممکن است بعداً توسط بازی load شود.

## CSP ناسازگار است

نسخه از فایل‌های رایج زیر `extension` خوانده می‌شود. برخی Buildها نسخه را در محل دیگری ثبت می‌کنند و نتیجه Unknown می‌شود. اگر `blockInstall` false باشد، کاربر می‌تواند پس از هشدار ادامه دهد؛ اگر true باشد باید CSP مناسب را دستی از منبع رسمی نصب کند.

## نصب نیمه‌کاره

UHM Backup/Rollback اجباری ندارد. اگر دسترسی فایل، آنتی‌ویروس یا فضای Disk در میانه Copy خطا دهد، بعضی فایل‌ها ممکن است نصب شده باشند. Log و Preview را بررسی، فایل‌های مود را با نسخه اصلی مقایسه و در صورت نیاز Steam Verify Integrity اجرا کنید. UHM هیچ فایل بازی را خودکار حذف نمی‌کند.

## Refresh همیشه آفلاین است

- Settings → تست اتصال را اجرا کنید.
- `catalogUrl` پیش‌فرض به branch اصلی GitHub اشاره می‌کند؛ تا Merge/انتشار فایل ممکن است 404 باشد.
- Proxy سازمانی یا TLS inspection می‌تواند PowerShell را block کند.
- Cache معتبر یا کاتالوگ Bundled همچنان نمایش داده می‌شود.

## Log شامل چه چیزی است؟

JSONL زمان، Event، Mod، URL بدون Query، Path مقصد، Hash، HTTP code، مدت و Error را دارد. رمز و Token Redact می‌شوند. Path ممکن است نام کاربری Windows را آشکار کند؛ Log را بدون بررسی عمومی نکنید.
