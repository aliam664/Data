# راهنمای UHM Catalog Manager

برای اضافه‌کردن مود بدون ویرایش دستی JSON، فایل زیر را اجرا کنید:

```text
catalog\UHM-Catalog-Manager.cmd
```

این ابزار یک پنجره Native WPF باز می‌کند و فایل EXE اختصاصی ندارد.

## امکانات

- نمایش و جست‌وجوی رکوردهای فعلی
- ساخت رکورد جدید یا Clone یک رکورد به‌عنوان Template
- تولید خودکار ID یکتا از نام انگلیسی
- فرم مرحله‌ای اطلاعات، دانلود، نصب/CSP، رسانه و Preview JSON
- بررسی HTTPS لینک رسمی و دانلود با درخواست HEAD
- انتخاب آرشیو محلی برای محاسبه خودکار Size و SHA-256
- عدم کپی فایل مود به Repository
- انتخاب Cover و Gallery و آماده‌سازی کپی در `images/<category>`
- تولید Raw GitHub URL تصاویر
- اعتبارسنجی با همان `Test-UhmModRecord` و `Test-UhmCatalog` لانچر
- کنترل ID تکراری، تاریخ، Hash، Password، CSP و Install Root
- نمایش Preview بدون نشان‌دادن Password
- ساخت Backup پیش از هر تغییر
- ذخیره Atomic فایل `catalog.json`
- افزایش پیشنهادی نسخه کاتالوگ به قالب `YYYY.MM.DD.N`
- عدم وجود قابلیت حذف رکورد

## روند پیشنهادی افزودن مود

1. در تب «اطلاعات اصلی»، نام انگلیسی و فارسی، سازنده، دسته و نسخه را وارد کنید.
2. روی «ساخت ID» بزنید و شناسه تولیدشده را بررسی کنید.
3. URL صفحه رسمی و لینک مستقیم HTTPS را وارد کنید.
4. اگر فایل رسمی را در اختیار دارید، «انتخاب فایل برای Hash و حجم» را بزنید. فایل فقط خوانده می‌شود و داخل GitHub کپی نمی‌شود.
5. Install Type و Install Root را دقیق تعیین کنید.
6. نیازمندی CSP، Pure، Sol و Content Manager را ثبت کنید.
7. Cover و Gallery مجاز را انتخاب کنید یا URL رسمی HTTPS وارد کنید.
8. Checkbox تأیید مجوز لینک‌ها/تصاویر را فقط پس از بررسی واقعی فعال کنید.
9. «اعتبارسنجی کامل» و سپس Preview JSON را بررسی کنید.
10. «افزودن امن به catalog.json» را بزنید و پیام نهایی را تأیید کنید.

## تصاویر محلی

وقتی تصویر محلی انتخاب می‌شود، تا قبل از Save کپی انجام نمی‌شود. هنگام Save:

- نام امن بر اساس Mod ID تولید می‌شود؛
- فایل موجود هرگز Overwrite نمی‌شود؛
- تصویر در پوشه دسته کپی می‌شود؛
- URL بر اساس `Raw image base URL` ساخته می‌شود.

برای Fork یا Repository دیگر، مقدار Raw base URL را پیش از انتخاب تصویر تغییر دهید.

## Backup و بازیابی

قبل از Save، نسخه فعلی کاتالوگ در مسیر زیر کپی می‌شود:

```text
data\cache\catalog-backups\catalog-YYYYMMDD-HHMMSS.json
```

Catalog Manager فایل قبلی را حذف نمی‌کند. در صورت نیاز، نگه‌دارنده می‌تواند Backup را پس از بررسی دستی بازیابی کند.

## لینک‌ها و CAPTCHA

تست لینک فقط یک درخواست HEAD با Timeout محدود انجام می‌دهد. پاسخ HTML برای Download یک هشدار است و می‌تواند به معنی صفحه واسط، Login یا CAPTCHA باشد. ابزار هیچ Login، Cookie، CAPTCHA bypass یا دانلود فایل پولی انجام نمی‌دهد.

## نکات انتشار

- فایل مود را Commit نکنید.
- برای مود پولی فقط URL رسمی سازنده را ثبت کنید.
- Hash رسمی و Size دقیق را ترجیحاً اجباری در Review در نظر بگیرید.
- بعد از Save، `catalog/schema.json` و تست‌های Catalog را اجرا کنید.
- تصاویر و `catalog.json` جدید را قبل از Commit در Git Diff بررسی کنید.
