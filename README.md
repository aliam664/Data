# UHM Launcher

لانچر فارسی و سبک برای مدیریت دانلود و نصب مودهای Assetto Corsa.

## اجرا

فایل `UHM-Launcher.cmd` را اجرا کنید. فایل CMD هسته PowerShell را راه‌اندازی می‌کند؛ بنابراین خروجی اصلی همچنان CMD است و هیچ EXE اختصاصی برای پروژه ساخته نمی‌شود.

رابط وب در `ui/index.html` قرار دارد و کاتالوگ در `catalog/catalog.json` مدیریت می‌شود.

## افزودن مود

فقط مدیر مخزن باید `catalog/catalog.json` را ویرایش کند. برای هر مود یک `downloadUrl`، تصویر و اطلاعات نصب ثبت کنید. فایل مود داخل GitHub نگهداری نمی‌شود؛ تنها لینک رسمی آن ثبت می‌شود.

برای آرشیو رمزدار، مقدار `password` در همان رکورد کاتالوگ قرار می‌گیرد. چون مخزن عمومی است، این رمز محرمانه محسوب نمی‌شود.

## پیش‌نیاز

- Windows 10/11
- PowerShell 5+
- 7-Zip برای RAR و 7Z (ZIP با tar ویندوز نیز قابل استخراج است)
- Assetto Corsa نسخه Steam

این نسخه با لینک مستقیم HTTPS کار می‌کند و CAPTCHA، ورود خودکار، دورزدن محدودیت سایت‌ها یا دانلود از صفحه‌های واسط را انجام نمی‌دهد.
